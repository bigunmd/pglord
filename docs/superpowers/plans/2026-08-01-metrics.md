# Prometheus Metrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Curated Prometheus metrics from both binaries — per-instance postgres metrics on the agent's :8008/metrics, control-plane metrics on the server's :8080/metrics — with scrape annotations rendered by default and opt-in prometheus-operator monitors in the Helm chart.

**Architecture:** The agent gains a `metrics` module that collects a `MetricsSample` over the existing short-lived unix-socket connection and renders it into a fresh registry per scrape (no stale series). The server gains a long-lived `Metrics` handle (registry + typed counters/gauges) threaded through `app::build()` and the existing background loops. Discovery is annotations-first; the chart adds optional PodMonitor/ServiceMonitor.

**Tech Stack:** Rust (edition 2024), axum 0.8, `prometheus` crate 0.14 (default-features off), tokio-postgres, Helm.

Spec: `docs/superpowers/specs/2026-08-01-metrics-design.md`.

## Global Constraints

- `/metrics` on the server is merged AFTER the utoipa router like `/healthz` — it must never appear in `spec/openapi.yaml`. No `make openapi ui-client` regeneration is expected; `make openapi-check` must stay green.
- Agent `/metrics` always returns 200; postgres being down means `pglord_pg_up 0`, never a 5xx.
- Metric labels never carry instance identity (pod/namespace) — discovery supplies target labels.
- Clippy warns on `unwrap_used`: use `expect("...")` for infallible registrations, `unwrap_or_default()` elsewhere.
- Two install paths stay in sync: any annotation added to `charts/pglord/templates/deployment.yaml` is added to `deploy/k8s/deployment.yaml` too.
- `prometheus.io/` remains an unreserved annotation prefix in `workload.rs`.

```rust
fn gauge(reg: &Registry, name: &str, help: &str, value: f64) {
    let g = Gauge::new(name, help).expect("static metric name");
    reg.register(Box::new(g.clone())).expect("unique metric name");
    g.set(value);
}

fn gauge_vec(reg: &Registry, name: &str, help: &str, label: &str, values: &[(String, f64)]) {
    if values.is_empty() {
        return;
    }
    let v = GaugeVec::new(Opts::new(name, help), &[label]).expect("static metric name");
    reg.register(Box::new(v.clone())).expect("unique metric name");
    for (key, value) in values {
        v.with_label_values(&[key]).set(*value);
    }
}

pub fn render(sample: &MetricsSample) -> String {
    let reg = Registry::new();
    gauge(
        &reg,
        "pglord_pg_up",
        "1 if the postgres stats query succeeded.",
        if sample.pg_up { 1.0 } else { 0.0 },
    );
    if let Some(primary) = sample.primary {
        gauge(
            &reg,
            "pglord_instance_primary",
            "1 on the primary, 0 on a standby.",
            if primary { 1.0 } else { 0.0 },
        );
    }
    if let Some(v) = sample.wal_lsn_bytes {
        gauge(
            &reg,
            "pglord_pg_wal_lsn_bytes",
            "Current WAL LSN as bytes: write position on the primary, replay position on a standby.",
            v,
        );
    }
    if let Some(v) = sample.replication_lag_seconds {
        gauge(
            &reg,
            "pglord_pg_replication_lag_seconds",
            "Standby only: seconds since the last replayed transaction.",
            v,
        );
    }
    gauge_vec(
        &reg,
        "pglord_pg_standby_replay_lag_bytes",
        "Primary only: replay lag in bytes per connected standby.",
        "standby",
        &sample.standby_replay_lag_bytes,
    );
    gauge_vec(
        &reg,
        "pglord_pg_connections",
        "Backends by state from pg_stat_activity.",
        "state",
        &sample.connections,
    );
    if let Some(v) = sample.max_connections {
        gauge(&reg, "pglord_pg_max_connections", "max_connections setting.", v);
    }
    gauge_vec(
        &reg,
        "pglord_pg_database_size_bytes",
        "Database size in bytes, non-template databases.",
        "database",
        &sample.database_size_bytes,
    );
    if let Some(v) = sample.pending_restart {
        gauge(
            &reg,
            "pglord_pg_pending_restart",
            "1 if settings are staged that need a restart.",
            if v { 1.0 } else { 0.0 },
        );
    }
    let mut buf = Vec::new();
    if TextEncoder::new().encode(&reg.gather(), &mut buf).is_err() {
        return String::new();
    }
    String::from_utf8(buf).unwrap_or_default()
}
```

```rust
/// Collect a sample. Any failure returns the `Default` (pg_up = false) sample:
/// a scrape must never 5xx just because postgres is down.
pub async fn collect(cfg: &Config) -> MetricsSample {
    match try_collect(cfg).await {
        Ok(sample) => sample,
        Err(err) => {
            tracing::debug!(%err, "metrics collection failed");
            MetricsSample::default()
        }
    }
}

async fn try_collect(cfg: &Config) -> anyhow::Result<MetricsSample> {
    let mut conn_str = format!(
        "host={} port={} user={} dbname=postgres connect_timeout=2",
        cfg.socket_dir.display(),
        cfg.port,
        cfg.superuser
    );
    if !cfg.superuser_password.is_empty() {
        conn_str.push_str(&format!(" password={}", cfg.superuser_password));
    }
    let (client, connection) = tokio_postgres::connect(&conn_str, tokio_postgres::NoTls).await?;
    let conn_task = tokio::spawn(connection);

    let row = client
        .query_one(
            "SELECT pg_is_in_recovery(), \
             pg_wal_lsn_diff(CASE WHEN pg_is_in_recovery() \
                                  THEN pg_last_wal_replay_lsn() \
                                  ELSE pg_current_wal_lsn() END, '0/0')::float8, \
             CASE WHEN pg_is_in_recovery() \
                  THEN extract(epoch from now() - pg_last_xact_replay_timestamp())::float8 END, \
             EXISTS(SELECT 1 FROM pg_settings WHERE pending_restart), \
             current_setting('max_connections')::float8",
            &[],
        )
        .await?;
    let in_recovery: bool = row.get(0);
    let mut sample = MetricsSample {
        pg_up: true,
        primary: Some(!in_recovery),
        wal_lsn_bytes: row.get(1),
        replication_lag_seconds: row.get(2),
        max_connections: row.get(4),
        pending_restart: Some(row.get(3)),
        ..Default::default()
    };

    if !in_recovery {
        // pg_current_wal_lsn() errors during recovery, so primary only.
        for row in client
            .query(
                "SELECT application_name, \
                 pg_wal_lsn_diff(pg_current_wal_lsn(), replay_lsn)::float8 \
                 FROM pg_stat_replication WHERE replay_lsn IS NOT NULL",
                &[],
            )
            .await?
        {
            sample.standby_replay_lag_bytes.push((row.get(0), row.get(1)));
        }
    }
    for row in client
        .query(
            "SELECT COALESCE(state, 'unknown'), count(*)::float8 \
             FROM pg_stat_activity GROUP BY 1",
            &[],
        )
        .await?
    {
        sample.connections.push((row.get(0), row.get(1)));
    }
    for row in client
        .query(
            "SELECT datname, pg_database_size(datname)::float8 \
             FROM pg_database WHERE NOT datistemplate",
            &[],
        )
        .await?
    {
        sample.database_size_bytes.push((row.get(0), row.get(1)));
    }
    drop(client);
    conn_task.abort();
    Ok(sample)
}
```

```rust
//! Control-plane metrics: one long-lived registry with typed handles, cloned
//! into the background loops. Per-cluster series are removed on cluster
//! deletion via forget_cluster so deleted clusters do not linger.

use prometheus::{Encoder, IntCounterVec, IntGauge, IntGaugeVec, Opts, Registry, TextEncoder};

#[derive(Clone)]
pub struct Metrics {
    registry: Registry,
    pub reconcile_total: IntCounterVec,
    pub failover_total: IntCounterVec,
    pub backup_runs_total: IntCounterVec,
    pub instances_ready: IntGaugeVec,
    pub instances: IntGaugeVec,
    pub clusters: IntGauge,
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn recorded_series_appear_in_render() {
        let m = Metrics::new();
        m.clusters.set(2);
        m.reconcile_total.with_label_values(&["demo", "ok"]).inc();
        m.failover_total.with_label_values(&["demo", "auto"]).inc();
        m.backup_runs_total
            .with_label_values(&["demo", "full", "succeeded"])
            .inc();
        m.instances_ready.with_label_values(&["demo"]).set(3);
        let out = m.render();
        assert!(out.contains("pglord_clusters 2"));
        assert!(out.contains("pglord_reconcile_total{cluster=\"demo\",outcome=\"ok\"} 1"));
        assert!(out.contains("pglord_failover_total{cluster=\"demo\",trigger=\"auto\"} 1"));
        assert!(out.contains(
            "pglord_backup_runs_total{cluster=\"demo\",kind=\"full\",outcome=\"succeeded\"} 1"
        ));
        assert!(out.contains("pglord_cluster_instances_ready{cluster=\"demo\"} 3"));
    }

    #[test]
    fn forgetting_a_cluster_drops_its_series() {
        let m = Metrics::new();
        m.reconcile_total.with_label_values(&["gone", "ok"]).inc();
        m.instances_ready.with_label_values(&["gone"]).set(1);
        m.instances.with_label_values(&["gone"]).set(1);
        m.forget_cluster("gone");
        let out = m.render();
        assert!(!out.contains("cluster=\"gone\""));
    }

    #[test]
    fn each_handle_is_independent() {
        // Two Metrics must not share a registry (fresh test state).
        let a = Metrics::new();
        let b = Metrics::new();
        a.clusters.set(5);
        assert!(!b.render().contains("pglord_clusters 5"));
    }
}
```

```rust
fn counter_vec(reg: &Registry, name: &str, help: &str, labels: &[&str]) -> IntCounterVec {
    let v = IntCounterVec::new(Opts::new(name, help), labels).expect("static metric name");
    reg.register(Box::new(v.clone())).expect("unique metric name");
    v
}

fn gauge_vec(reg: &Registry, name: &str, help: &str) -> IntGaugeVec {
    let v = IntGaugeVec::new(Opts::new(name, help), &["cluster"]).expect("static metric name");
    reg.register(Box::new(v.clone())).expect("unique metric name");
    v
}

impl Metrics {
    pub fn new() -> Metrics {
        let registry = Registry::new();
        let reconcile_total = counter_vec(
            &registry,
            "pglord_reconcile_total",
            "Reconcile passes per cluster by outcome.",
            &["cluster", "outcome"],
        );
        let failover_total = counter_vec(
            &registry,
            "pglord_failover_total",
            "Primary record changes by trigger (auto = orchestrator, manual = switchover API).",
            &["cluster", "trigger"],
        );
        let backup_runs_total = counter_vec(
            &registry,
            "pglord_backup_runs_total",
            "Finished backup runs by kind and outcome.",
            &["cluster", "kind", "outcome"],
        );
        let instances_ready = gauge_vec(
            &registry,
            "pglord_cluster_instances_ready",
            "Instances currently reporting ready.",
        );
        let instances = gauge_vec(
            &registry,
            "pglord_cluster_instances",
            "Instances the cluster should have.",
        );
        let clusters = IntGauge::new("pglord_clusters", "Number of cluster specs.")
            .expect("static metric name");
        registry
            .register(Box::new(clusters.clone()))
            .expect("unique metric name");
        Metrics {
            registry,
            reconcile_total,
            failover_total,
            backup_runs_total,
            instances_ready,
            instances,
            clusters,
        }
    }

    pub fn render(&self) -> String {
        let mut buf = Vec::new();
        if TextEncoder::new()
            .encode(&self.registry.gather(), &mut buf)
            .is_err()
        {
            return String::new();
        }
        String::from_utf8(buf).unwrap_or_default()
    }

    /// Drop every series labeled with a deleted cluster. Counter label sets
    /// are finite and known, so removal is by enumeration.
    pub fn forget_cluster(&self, cluster: &str) {
        let _ = self.instances_ready.remove_label_values(&[cluster]);
        let _ = self.instances.remove_label_values(&[cluster]);
        for outcome in ["ok", "error"] {
            let _ = self.reconcile_total.remove_label_values(&[cluster, outcome]);
        }
        for trigger in ["auto", "manual"] {
            let _ = self.failover_total.remove_label_values(&[cluster, trigger]);
        }
        for kind in ["full", "diff", "incr"] {
            for outcome in ["succeeded", "failed"] {
                let _ = self
                    .backup_runs_total
                    .remove_label_values(&[cluster, kind, outcome]);
            }
        }
    }
}

impl Default for Metrics {
    fn default() -> Metrics {
        Metrics::new()
    }
}
```

```rust
async fn sync_all(
    client: &kube::Client,
    cms: &Api<ConfigMap>,
    ns: &str,
    metrics: &crate::metrics::Metrics,
    known: &mut std::collections::HashSet<String>,
) -> anyhow::Result<()> {
    let specs = cms
        .list(&kube::api::ListParams::default().labels(&spec_label_selector()))
        .await?;
    metrics.clusters.set(specs.items.len() as i64);
    let mut current = std::collections::HashSet::new();
    for cm in &specs.items {
        let (spec, owner) = match configmap_to_spec(cm) {
            Ok(parsed) => parsed,
            Err(err) => {
                tracing::warn!(cm = ?cm.metadata.name, %err, "skipping unparseable spec");
                continue;
            }
        };
        current.insert(spec.name.clone());
        if let Err(err) = spec.validate() {
            tracing::warn!(cluster = %spec.name, %err, "skipping invalid spec");
            continue;
        }
        let primary_pod = recorded_primary(cm, &spec.name);
        if let Err(err) = apply_cluster(client, ns, &spec, &owner, &primary_pod).await {
            metrics
                .reconcile_total
                .with_label_values(&[&spec.name, "error"])
                .inc();
            tracing::warn!(cluster = %spec.name, %err, "apply failed");
        } else {
            metrics
                .reconcile_total
                .with_label_values(&[&spec.name, "ok"])
                .inc();
            tracing::debug!(cluster = %spec.name, "reconciled");
        }
    }
    for removed in known.difference(&current) {
        metrics.forget_cluster(removed);
    }
    *known = current;
    Ok(())
}
```
